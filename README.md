# Basic Java OOP — Learning Journey 📘

A hands-on collection of Java exercises and mini-programs documenting my journey through **Object-Oriented Programming (OOP)** and core Java concepts — from the fundamentals of classes and objects to working with databases via JDBC.

Each folder is a self-contained topic with small, focused examples I've written while learning. This repo is a personal learning log, not a production project — expect it to grow as I cover more topics.

## 🚀 Getting Started

### Prerequisites

- [ ] JDK 17+ installed
- [ ] A Java IDE (IntelliJ IDEA, Eclipse, VS Code with Java extensions) or just a terminal + `javac`
- [ ] For the `JDBC` module: a running database (e.g., MySQL) and its JDBC driver

### Running an Example

Each topic folder contains standalone `.java` files. To compile and run one manually:

```bash
git clone https://github.com/navin-net/Basic-Java-OOP.git
cd Basic-Java-OOP

# Compile a specific file
javac ClassandObject/SomeExample.java

# Run it
java ClassandObject.SomeExample
```

Or open the whole repo in your IDE and run individual files directly.

### Main Entry Point

`Main.java` at the root can be used to run and test snippets as needed.
